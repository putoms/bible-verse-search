# 성경 구절 검색

책·장·절을 입력하거나 선택해서 성경 구절(개역한글판)을 찾아주는 간단한 웹 앱입니다.
HTML / CSS / 순수 JavaScript로만 만들어져 있어 빌드나 설치 없이 동작합니다.

## 주요 기능

- **직접 입력 검색**: `요한복음 3:16` 형식으로 입력해서 검색
- **선택 검색**: 책 / 장 / 절을 드롭다운에서 골라 검색
- **본문 복사**: 검색된 구절을 클립보드에 복사
- **최근 검색**: 최근 10개 검색 기록을 브라우저(LocalStorage)에 저장
- 로딩 / 오류 메시지 표시

## 실행 방법

1. 이 저장소를 내려받습니다.
2. `index.html`을 브라우저에서 엽니다. (별도 서버·빌드 불필요)

인터넷 연결이 필요합니다. 구절은 공개 API([api.midvash.com](https://api.midvash.com))에서 가져오며, API 키나 회원가입은 필요 없습니다.

## 사용법

입력창에 `책이름 장:절` 형식으로 입력합니다. 책 이름은 한글 정식 명칭이어야 합니다.

```
요한복음 3:16
시편 23:1
```

## 파일 구성

| 파일 | 설명 |
| --- | --- |
| `index.html` | 화면 구조 |
| `style.css` | 화면 디자인 |
| `script.js` | 검색, API 호출, 복사, 최근 검색 기능 |
| `lesson.md` | `script.js`를 주제별로 설명한 학습 가이드 |
